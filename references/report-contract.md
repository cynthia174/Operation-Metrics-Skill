# Report Contract

- Full reports retain the existing five-screen structure and order.
- Consume only facts, deterministic metrics, and official Rule Result.
- Express rule hits as supplied; a miss or unchecked rule is not “没有风险” or “检查通过”.
- Summarize data gaps with the missing input and affected analysis.
- Screen 5 summarizes screens 1–4 and introduces no new numbers or detail data.
