第二屏 · 规则诊断

R15（渠道集中度）: 🔴 94-98%依赖外部付费投放

| 数据 | 判定 |

| --- | --- |

| 外部获客成本占总获客成本比 | 94-98% |

| 覆盖平台 | 抖音/腾讯/百度三平台——分散了单平台断流风险 |

| 如果三大平台同时大幅提价 | 利润模型直接承压 |

不是"抖音是大渠道"——是"除了付费投放，没有其他渠道"。三平台避免了单点故障，但没有改变"全部流量靠买"的结构性脆弱。

R18（付费流量占比）: 🔴 >95%付费

自然流量≈0。品牌搜索量≈0。SEO≈0。全部流量靠买。

R17（亏损渠道）: 不适用

S3 规则补丁明确：体验营模式下首单ROI<1 不是Red Flag。改为关注：

| 指标 | 趋势 | 判定 |

| --- | --- | --- |

| 外部例子数 | 484K→137K(-72%) | 🔴 进水口在萎缩 |

| 外部转化率 | 4.4%→5.9%(+34%) | 🟢 转化效率在改善 |

| 外部获客成本率 | 41%→34% | 🟢 成本在优化 |

三句话: 进水口越来越小，但每一滴水的利用率越来越高。问题是——利用率改善的速度（+1.5pp/年）赶不上进水口萎缩的速度（-72%/年）。

渠道依赖度的战略含义

获客型产品三兄弟（普拉提/中医变美/瑜伽-杨淇）全部高度依赖外部投放。这条线的风险不在单一品类——在于整个品类组的渠道单一。

深耕型产品（逆龄女神）的渠道结构天然更健康：54%内部流转。但它的"内部渠道"供应取决于获客型产品的用户池大小——这是一个"二级依赖"：逆龄女神不依赖投放，但依赖瑜伽-杨淇，而瑜伽-杨淇依赖投放。

第四屏 · 内部渠道——被忽视的金矿

内部获客现状

| 指标 | 数据 |

| --- | --- |

| 内部获客成本占比 | 始终2-3% |

| 内部例子数 | 稳定2-4万/月 |

| 内部流转ROI | 高于外部（无需投放费） |

内部渠道的三个未开发价值

1. 零边际获客成本。 内部流转不需要投放费——只需要运营人力。一个用户从瑜伽流到逆龄女神，新增收入几乎全部是利润。

2. 渠道稳定性。 外部例子数波动剧烈（94K→567K），内部例子数始终在1.6-4万/月。内部渠道不受平台算法影响。

3. 转化效率天然高。 内部流转的用户已经信任平台——不需要"说服他们这是正经课"。

为什么内部渠道占比只有2%

不是因为没价值——是因为没人负责。品类各有自己的P&L和投放预算，品类间的用户流转不归属任何人的KPI。品类联邦制在组织设计上就扼杀了内部渠道。

第五屏 · 转介绍塌方

从3,600→918/月

转介绍佣金行数据验证：一年内-75%。

根因推断（三层）

| 层级 | 原因 | 证据 |

| --- | --- | --- |

| 表层 | 体验营用户无推荐动机 | 1元品用户不好意思推荐给朋友 |

| 中层 | 推荐未产品化 | 无激励/无入口/无追踪 |

| 深层 | 品牌无社交价值 | 用户自己买但不推荐=产品好但品牌不存在。推荐"杨淇的瑜伽课"可以，推荐"兴趣岛"不行。 |

转介绍塌方不是渠道问题——是品牌问题的症状。如果一个品牌有价值，用户会"忍不住"告诉朋友。如果用户沉默了，不是激励不够——是没什么好说的。

第六屏 · S3 → 加减乘除

四个结论

结论(1): 外部付费投放依赖是结构性脆弱，不是经营级风险。 不是"优化投放ROI"能解决的——是整个商业模型绑在付费流量上。94-98%的依赖度意味着平台规则变化会直接传导到营收。三平台（抖音/腾讯/百度）分散了单平台断流风险，但没有改变"全部流量靠买"的底层逻辑。

结论(2): 内部渠道是唯一未被开采的增长引擎。 2-3%的获客成本占比vs零边际成本——这个差距就是机会。但开采内部渠道的前提是品类间KPI从"各自P&L"变成"用户P&L"。

结论(3): 转介绍塌方不是S3该追问的问题。 体验营用户天然无推荐动机——短期不构成独立战场。长期解决靠品牌建设（S4），不靠渠道优化（S3）。

结论(4): S3 对体验营模式的重心 = 获客量趋势 + 转化效率。 不做ROI判断。当前: 进水口萎缩（-72%） > 转化率改善（+1.5pp）= 净效果仍然是缩量。
