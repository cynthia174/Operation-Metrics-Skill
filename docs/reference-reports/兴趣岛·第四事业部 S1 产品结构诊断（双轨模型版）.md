深耕型产品的三个战略发现

1. 它们吃的是获客型产品的用户溢出。 瑜伽-杨淇的用户练了半年后，一部分自然流向逆龄女神和面部驻颜。深耕型产品不是独立增长——是寄生增长。供水塔一倒，全部断流。

2. 反哺力是深耕型最被低估的战略价值。 如果一个用户买了逆龄女神后，在瑜伽-杨淇的留存率从40%提升到60%，逆龄女神不只是自己赚552万——它在帮瑜伽-杨淇锁住用户。这个数据能直接回答要不要投资源建深耕型产品线。

3. 横复不是增收动作——是深耕型产品的供给侧改革。 没有横复=没有老用户池增量=逆龄女神和面部驻颜的增长天花板锁死。

第七屏 · 诊断结论 + S1→加减乘除

六个结论（双轨视角）

结论(1)：瑜伽-杨淇是供水塔——不只是金牛。 贡献66%利润，且是整个事业部内部获客池的来源。它一倒，深耕型产品全部断流。5月异常验证是第一优先级。

结论(2)：获客型产品分两档——东方养正+瑜伽-杨淇健康，普拉提+中医变美病灶在毛利率。 后两者的根因不是获客——是毛利率只有同品类的一半甚至1/4。获客优化救不了它们。

结论(3)：深耕型产品利润密度是获客型的2.4倍——但体量太小，且寄生在获客型产品的用户池上。 增长天花板=供水塔的用户规模×横复转化率。

结论(4)：两类产品不能用同一套KPI。 获客型考核获客边际利润，深耕型考核渗透率+反哺力。把逆龄女神和普拉提放在同一个"获客成本率"框架下比较是系统性错误。

结论(5)：横复的战略地位升级。 它不是增收动作——对深耕型产品是供给侧改革，对获客型产品是用户资产变现。没有横复，深耕型产品没有未来。

结论(6)：尾部5品类月失血94万，毛利率全部为负。止损纪律为零。
