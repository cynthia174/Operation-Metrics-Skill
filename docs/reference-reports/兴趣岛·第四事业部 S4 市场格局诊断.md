一、市场底盘

人口底盘

第四事业部的核心用户画像：40+ 女性，有自我投资意愿和支付能力。

40-65 岁女性人口：约 2.8 亿（七普数据）

其中城镇人口占比约 65%：约 1.8 亿

有线上消费习惯的：保守估计 40%，约 7,200 万

可触达人群（信息流覆盖）：约 3,000-5,000 万 🅴

消费底盘

用户 LTV 锚定：

第四事业部客单价约 200-500 元/阶，平均一阶复购约 1.5 次

单品用户 LTV ≈ 257 元 🅴

生态用户（跨 2+ 品类）LTV ≈ 800-1,500 元 🅴

对标相邻消费品类："一个用户的年度消费 ≈ 一瓶中档面霜 ≈ 两节线下瑜伽私教课"——不是高价品，是高频中价的"日常自我投资"。

对手不只是同品类竞品——养生品、线下瑜伽馆、旅游都在抢同一笔预算。当品牌没有强到让客户"省下其他消费来买你"时，竞争场就是预算池而非品类池。 第四事业部目前显然处于预算池竞争——用户不是因为"兴趣岛最好"而买，是因为"刚好刷到了、价格不贵、试试看"。

三、护城河评估（双轨视角）

| 壁垒维度 | 评级 | 依据 | 双轨含义 |

| --- | --- | --- | --- |

| 课程阶梯 | 🟢 强 | 一阶→二阶→三阶→四阶，复用率 71.8% | 对单品用户有效，对生态用户是"基础但不充分" |

| 班主任体系 | 🟢 强 | 陪练+纠正+习惯养成，是课程差异化的核心 | 是锁客的最强武器，但未被产品化为生态用户资产 |

| 复购留存 | 🟡 中 | 靠课程吸引力，不靠锁客机制 | 单品用户一阶流失 50%，生态用户无主动运营 |

| 获客效率 | 🟡 中 | 三平台（抖音/腾讯/百度）分散风险，外部占比 94-98% | 多平台降低了单点故障——但没有改变"全部流量靠买"的底层逻辑 |

| 品牌 IP | 🔴 弱 | 品类名=老师名，用户跟老师走不跟品牌走 | S2 结论"客户资产不存在"的直接原因 |

| 品类矩阵 | 🟡 中 | 10+ 品类覆盖体态/面容/内在，但矩阵是"品类联邦" | 品类间有需求关联但无产品化横复路径 |

| 跨事业部协同 | 🔴 弱 | 三大学院各自为战 | 生态用户的"生态"应该是全公司的，不只是第四事业部 |

护城河画像：后端有壁垒（课程阶梯 + 班主任），前端是敞开的（品牌弱 + 付费投放依赖 + 锁客缺失）。像一个固若金汤的城堡，城门没锁——进来的用户如果能熬过前两阶就留得住，但大量用户在城门口就流失了。

| 双轨补丁：护城河对"单品用户"和"生态用户"的强度完全不同。单品用户面对的是无品牌、无关系、无锁定的三重脆弱。生态用户自己绑定了多品类后，转换成本上升——但这是"用户自己建的护城河"，不是兴趣岛建的。 |

逆风叠加分析

两个逆风同时打到同一块短板：

KOL 个体户化 → 攻击品牌/IP 短板（🔴）：老师自带流量后，留在兴趣岛的动力是"平台给后端服务"，但兴趣岛没有把后端服务变成老师离不开的资产

信息流红利消退 → 攻击获客效率（🟡 中）：三平台 CPA 同步上升，获客管道整体变窄。三平台分散了单平台政策风险，但没有抵消"投放效率长期下行"的趋势

乘数效应降级：与单平台假设（抖音独占）不同，三平台结构避免了单点故障式乘数效应。但两个逆风的合力仍然存在——获客变贵 × 品牌没有独立获客能力 = 对投放的依赖不是战术选择，而是结构锁定。一旦行业竞争加剧推高三平台 CPA 或平台同时调整算法，第四事业部的获客成本可能非线性跃升——而品牌本身无法接住流量。

五、定位选择

当前定位诊断

用户心智中，兴趣岛·第四事业部是什么？

真相：用户不买"兴趣岛"，买"杨淇的瑜伽课"、"东方养正"、"逆龄女神"。 品牌名只是一个 App 下载入口，不是决策因素。品类名=老师名，品类之间是"联邦制"而非"平台制"。

这导致三个问题：

品牌无累积效应——每推一个新课等于从零开始

品类间无协同——用户买瑜伽和买逆龄是两件无关的事（即使 S1 证明有需求关联）

无法防御 KOL 流失——老师走了用户就走了

可选方向

方向 A：产品IP ⚠️ 品类名待定

| KK 2026-07-15 批示：美体教练未通过。 暂时用"产品IP"作为方向占位——指的是"打造一个独立于老师个人品牌的产品 IP"，具体品类名和表达方式待后续确定。 |

| --- |

方向：产品IP——区别于"品类名=老师名"的现状，打造一个用户记住的是"产品"而非"老师个人"的 IP

差异化基础：跨品类三合一（瑜伽调体态 + 驻颜修面容 + 中医调内在），一个体系而非单一品类

信任状：50% 用户一阶续二阶——不是课好，是真有人带、练出惯性了

待定事项：具体品类名、品牌名、表达方式

方向 B：品类平台（全品类覆盖、不做单一定位）

核心策略：保持现状，多品类并行，靠品类矩阵提供"一站式自我投资"

优势：已验证的品类矩阵有真实需求，横复 29,000/月在自然增长

风险：没有锚点品类的平台 = 用户记不住 = 品牌不存在（S2 结论的直接后果）

倾向建议：A+B 混合定位——产品IP做矛，品类矩阵做盾

| 角色 | 品类 | 策略 |

| --- | --- | --- |

| 矛 | 产品IP（以瑜伽-杨淇为核心 + 东方养正品牌） | 集中资源打爆一个心智锚点。前端获客、内容、广告语全部围绕"产品IP"。目标是让"产品IP=兴趣岛" |

| 盾 | 品类矩阵（逆龄女神/面部驻颜/中医变美/普拉提） | 不做大规模前端获客，靠横复和内部转化自然增长。后端做锁客和 LTV 拉升 |

| 补短板 | 转介绍 + 多平台投放优化 | 转介绍从 0.4%→5%：品牌有社交价值后转介绍才可能复活。三平台投放持续优化获客成本率（41%→34% 趋势维持） |

这个混合定位和 S1-S3 全部结论咬合：

S1 产品双轨：矛=获客型（瑜伽-杨淇），盾=深耕型（逆龄女神等）+ 部分获客型（东方养正/中医变美）

S2 用户双轨：矛负责把单品用户拉进来，横复负责把单品用户升级为生态用户

S3 渠道：矛优化三平台投放效率（已有改善趋势 41%→34%），盾解决"内部渠道只有 2-3%"（产品化横复路径）

S4 竞争：矛的差异化（跨品类三合一教练）是三平台 KOL 跨不出的——瑜伽 KOL 能做瑜伽，但做不了驻颜+中医；驻颜 KOL 能做面容，但做不了体态+内在

六、核心结论

一句话：第四事业部不是在饱和市场里抢份额——是在渗透率 <0.07% 的巨大市场里，因为品牌不存在而卡在付费投放管道上。关键矛盾不是"市场不够大"，是"有需求、有产品、有复购，但没有品牌把这三者串成一个可持续的生意"。

市场够大——窄义 TAM ~1,150 亿，市占率 <0.07%。渗透率极低，天花板极远。

头号敌人是三平台信息流 KOL——抖音/腾讯/百度上的瑜伽/健身/养生 KOL，同一竞价池、同一品类、同一人群。三平台分散了单平台风险，但未改变 KOL 竞争烈度。

护城河在后端，不在前端——课程阶梯 + 班主任体系是真壁垒，但品牌/IP 是致命短板，获客效率是中等问题（三平台分散风险）。城堡固若金汤，城门没锁。

用户双轨暴露了护城河的二元性——对单品用户，护城河几乎为零；对生态用户，护城河是"用户自己建的"而非品牌建的。横复产品化 = 把用户自建的护城河变成品牌资产。

定位 = 产品IP做矛 + 品类矩阵做盾——和 S1 产品双轨、S2 用户双轨、S3 渠道诊断全部咬合。单点打爆"产品IP"心智锚点，其余品类靠横复自然增长。
