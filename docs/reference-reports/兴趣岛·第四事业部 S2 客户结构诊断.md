第〇屏 · 双类用户——单品用户 vs 生态用户

| S1 建立了产品的双轨分类（获客型/深耕型）。S2 在用户维度发现了同构但独立的分裂——不是产品双轨的镜像，而是用户跟谁发生关系的本质差异。 |

| --- |

双轨定义

|  | 单品用户 | 生态用户 |

| --- | --- | --- |

| 定义 | 只与 1 个品类发生关系的用户 | 已跨 2+ 品类消费的用户 |

| 来源 | 外部获客（抖音→瑜伽-杨淇） | 单品用户完成首次横复后形成 |

| 关系对象 | 跟品类/老师，不跟兴趣岛 | 跟"多品类组合"发生关系 |

| LTV 模式 | 单品类生命周期价值 | 跨品类生态总价值 |

| 流失成本 | 几乎为零（换 App 无损失） | 绑定 2+ 品类后转换成本上升 |

| 核心指标 | 首单→二阶转化率 | 跨品类数 × 单品类深度 |

| 现状体量 | 绝大多数用户 | 横复 29,000/月（自然增长中） |

与产品双轨的关系——是交叉，不是镜像

产品双轨的分法依据：产品如何获客（外部投放 vs 内部转化）。
用户双轨的分法依据：用户跟谁发生关系（单一品类 vs 多品类生态）。

两者的对应关系不是 1:1：

| 场景 | 产品维度 | 用户维度 |

| --- | --- | --- |

| 只买瑜伽-杨淇 | 获客型 | 单品用户 |

| 瑜伽-杨淇 + 逆龄女神 | 获客 + 深耕 | 生态用户 |

| 只买东方养正 | 获客型 | 单品用户 |

| 东方养正 + 面部驻颜 + 中医变美 | 获客 + 获客 + 获客 | 生态用户 |

关键洞察：生态用户可以来自"全获客型组合"（如东方养正 + 中医变美），不需要深耕型产品参与。横复的驱动力是用户需求组合，不是产品类型。

为什么"单品 vs 生态"是兴趣岛用户维度的原生分类

对标方法论的发现：

Lisa「独立站用户资产四维度」：社媒 → 授权 → 交易 → 互动。兴趣岛缺失了授权资产这个中间层——用户买完就走，没有"已触达未深绑"的缓冲状态。

升级定位「增长四步」：触达 → 转化 → 锁定 → 扩增。兴趣岛做了触达和转化，但：

对单品用户：锁定和扩增是空的（没会员、没数据、没关系）

对生态用户：锁定和扩增是"用户自己做了但平台没识别、没强化"

23 万沉默用户的本质：他们是停留在"单品用户"状态后流失的人群。如果在流失窗口期内完成首次横复，就会被重新定义为"生态用户"——而生态用户的流失成本远高于单品用户。

双类用户的战略含义

单品用户和生态用户的价值逻辑完全不同，必须分开考核：

|  | 单品用户 | 生态用户 |

| --- | --- | --- |

| 增长引擎 | 外部获客效率 | 横复转化率 |

| 利润模型 | 单品类 LTV > CAC | 生态 LTV（跨品类总和） |

| 风险点 | 一阶流失 50% | 无产品化运营（靠自然流转） |

| 生命周期阶段 | 初创期指标（转化率） | 成长期指标（CLV/ARPU） |

| 战略动作 | 降低一阶流失 | 产品化横复路径 |

| ⚠️ 同一套 KPI 套两类用户 = 系统性指标错配。对应「生命周期目标指标矩阵」核心警示：用错阶段的指标，就是把资源浇到错误的方向上。 |

第一屏 · 客户全生命周期

用户旅程

| 体验营 → 初阶 → 一阶复购 → 二阶复购 → 三阶→四阶 → 横向跨品类复购<br>  ↑                                                        ↓<br> 外部投放                                          会员/转介绍（近乎为零） |

| --- |

| 双轨视角：以上旅程对两类用户含义不同。对单品用户，旅程终点是一阶流失（50%）或高阶流失。对生态用户，横复是旅程的"第二开端"——他们从此进入多品类组合消费。 |

| --- |

复购漏斗（26年1-5月均值）

| 品类 | 一阶→二阶 | 二阶→三阶 | 三阶→四阶 | 漏斗特征 |

| --- | --- | --- | --- | --- |

| 东方养正 | 51.7% | 68.2% | 66.9% | 最健康——每阶留存>50% |

| 逆龄女神 | 46.4% | 69.0% | 70.9% | 一阶流失大，后续极强 |

| 瑜伽-杨淇 | 43.5% | 60.8% | 54.9% | 供水塔——漏斗宽但稳 |

| 面部驻颜 | 44.4% | 45.5% | 29.0% | 二阶后流失严重 |

| 中医变美 | 44.0% | 32.9% | 42.0% | 二阶→三阶是最大断点 |

| 普拉提 | 37.8% | 53.2% | 52.9% | 一阶流失最大 |

发现: 一阶→二阶是全品类共同的断点。平均约50%的用户初阶结束后不再续费。二阶之后的留存反而更高（53-71%）。

事业部整体复购率

整体一阶复购率约 40%，复购收入占总营收 71.8%。用户不是一次性的——但留住用户的方式是被动的（靠课程阶梯自然流转），不是主动的（靠锁定、会员、数据、关系）。

| 双轨视角：71.8% 的复购占比里，单品用户的复购（同品类高阶）和生态用户的复购（跨品类）混在一起算，无法分拆——因为无客户级数据。 |

第二屏 · 客户资产诊断

四层资产视角下的客户结构

| 资产层 | S2 信号 | 数据支撑 |

| --- | --- | --- |

| 品牌资产 | 用户买的不是"兴趣岛"——是"杨淇的瑜伽课" | 品类名=老师名；用户跟老师走，不跟事业部走 |

| 产品IP资产 | 课程内容绑在老师个人 | 老师走=学员走；无自有IP |

| 客户关系资产 | 用户无锁定、无数据、无关系 | 会员3.4%、转介绍塌方75%、无客户级数据 |

| 组织能力资产 | 品类间复购能力差距大 | 一阶复购率差14pp |

| 双轨视角：客户关系资产的缺失，对单品用户意味着"无锁定"（流失无成本），对生态用户意味着"有锁定但平台看不见"（用户自己绑定了多品类，但平台没识别、没强化、没利用）。 |

| --- |

R9（客户利润质量）: 无客户级数据——致命盲区

不知道谁在赚钱、谁在亏钱。一个年消费1.5万的"三栖生态用户"和一个只上一次体验营就走的"一次性单品用户"——在后台是同一个人。

R11（LTV/CAC）: 只能做品类级间接估算

| 品类 | 估算LTV/CAC | 判定 |

| --- | --- | --- |

| 东方养正 | ~5x | 获客值钱 |

| 瑜伽-杨淇 | ~4x | 获客值钱 |

| 逆龄女神 | ~12x（内部获客） | 老用户转化极高效 |

| 面部驻颜 | ~6x | 内外双引擎 |

| 中医变美 | ~1.1x | 接近不赚钱 |

| 普拉提 | ~0.8x | 越投越亏 |

| 双轨盲区：以上 LTV/CAC 是"品类级单用户"LTV，不是"生态用户跨品类总 LTV"。一个生态用户的真实价值可能远高于任何一个品类的单品类 LTV——但无法计算，因为无客户级数据。 |

第三屏 · 用户留存与锁定

R23（老客复购）: 有复购、无锁定

复购占收入71.8%——用户确实在重复购买。但全部靠课程阶梯的"自然吸引力"，没有主动锁定机制。

| 锁客手段 | 渗透率 | 判定 |

| --- | --- | --- |

| 会员/年卡 | 3.4% | 几乎没有 |

| 社群/私域 | 未知 | 每阶解散重建 |

| 数据沉淀 | 无 | 练功记录/打卡数据归零 |

| 沉没成本 | 无 | 换一个App毫无损失 |

R27（首单粘性）: 一阶→二阶流失50%是最大机会

首单后50%用户不再续二阶。不是内容不好（二阶后留存60-70%说明内容好），是"从初阶到二阶的信任传递"断了——

初阶班主任到二阶换人了？

初阶结束到二阶开课有空白期？

二阶的"钩子"不够强？

R25（沉默客户）: 大量沉默用户未被触达

23.1万-31.6万用户上过初阶但未进二阶。如果唤回率5%，就是1.1-1.5万增量二阶用户。

| 双轨视角：23万沉默用户 = 停留在"单品用户"状态后流失的群体。唤回他们的最佳策略不是"再来上二阶"，而是"试一个完全不同的品类"——完成首次横复，从单品用户升级为生态用户。 |

第四屏 · 横向复购——隐藏的客户资产

横复现状

横复从 ~5,500/月自然增长到 29,000/月（+5倍），但完全是自然流转——无人设计路径、无人追踪、无人激励。

| 双轨视角：横复的本质 = 单品用户→生态用户的转化事件。29,000/月 = 每月有 29,000 次"升级"发生——但平台没有识别、没有庆祝、没有推动。 |

| --- |

横复的战略意义（双轨视角）

对获客型产品：用户多品类绑定=转换成本提升。一个在兴趣岛只练瑜伽的人随时能走，一个练瑜伽+逆龄+面部驻颜的人不会走。

对深耕型产品：横复=供给侧。逆龄女神54%的用户来自内部获客——没有横复就没有深耕型产品的生存空间。

对用户双轨：横复 = 单品用户晋升生态用户的唯一入口。产品化横复 = 加速这个晋升过程 = 提升整个用户池的流失成本。

横复的三层价值

| 层级 | 价值 | 现状 |

| --- | --- | --- |

| 增收 | 多卖课 | 29,000/月自然流转 |

| 锁客 | 多品类绑定=高转换成本 | 未被利用 |

| 供血 | 深耕型产品的用户来源 | 未被利用 |

第五屏 · 转介绍与社会证明

R28-R31（转介绍）: 从3,600→918/月塌方

一年内转介绍下降了75%。这不是"转介绍做不起来"——是"之前做过但没维持住"。

可能原因:

1元体验营用户不好意思推荐给朋友（"我给你推荐个1块钱的东西"）

推荐机制没产品化（无激励、无入口、无追踪）

品牌无社交价值（"兴趣岛"不是能拿来炫耀的名字）

| 双轨视角：转介绍在两类用户上的表现可能截然不同。生态用户（绑定了3个品类、花了1.5万）推荐动机远强于单品用户（只上过一次1元体验营）。但"无客户级数据"意味着这个假设无法验证。 |

| --- |

R29: 无转介绍数据——不知道谁来、从哪来

不知道新用户里多少是朋友推荐来的、多少是抖音刷到的。可以缺失数据，但不能缺失"想知道"的意愿。

第六屏 · 客户结构的战略判断

七个结论（S2视角·含双轨）

结论(1): 客户资产不存在——因为所有用户都是"单品用户"。
用户买的是课程、跟的是老师、留在的是品类。兴趣岛作为一个品牌，跟用户之间没有关系。平台上没有"生态用户"这个资产类别——即使每月29,000次横复证明用户已经在自发构建生态关系。

结论(2): 复购质量高但不可控。
71.8%的复购占比说明用户确实在重复购买——但全靠课程本身的吸引力，不是靠锁客机制。如果哪天课程品质下滑，复购会同步下滑——因为没有"即使课程一般也会续"的惯性。

结论(3): 一阶→二阶是最大的价值洼地。
50%的流失不是产品问题（二阶后留存60-70%证明产品好）——是运营问题。唤回一个老用户比获取一个新用户便宜5-10倍。

结论(4): 横复是唯一正在增长的客户资产——它本质是"单品→生态"的转化引擎。
29,000/月 vs 5,500/月（+5倍）——用户自己已经在跨品类买了。产品化这个行为 = S2 维度最大的增量。但产品化之前，先要建立"单品用户 vs 生态用户"的数据分类——否则不知道谁转化了、谁该转化。

结论(5): 转介绍塌方是被忽略的预警。
3,600→918——不是"转介绍不重要"，是"用户不愿意推荐"。这对一个"复购占比71.8%"的生意是危险的：用户自己买但不推荐 = 产品好但没有社交价值 = 品牌不存在。

结论(6): 客户级数据缺失是所有判断的瓶颈。
不知道谁是高价值用户、不知道流失去哪、不知道反哺力——S2 诊断里最重要的规则（R5/R9/R11/R40/R41）全部无法执行。

结论(7): 单品用户和生态用户必须分开考核。
同一套 KPI 套两类用户 = 系统性指标错配。单品用户看转化率和留存率（初创期指标），生态用户看跨品类 CLV 和反哺力（成长期指标）。在打通客户级数据之前，至少要在横复事件上做标记——识别出"刚完成首次横复的用户"作为生态用户起点。
