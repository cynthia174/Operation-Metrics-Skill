# 第三屏 · 获客成本信号

## 成本信号总览

当前渠道效率数据支持 CAC、CAC Rate、转化率和 ROI 的规则检查。规则结果中 R37 共 128 条命中，R36 共 28 条命中，说明成本信号既有单期跳升，也有连续上行。

## 持续上行渠道

| 信号 | 结果 |
| --- | --- |
| CAC 连续上行（R36） | 28 条命中 |
| CAC 单期跳升（R37） | 128 条命中 |

## 关键发现

## 发现：成本压力的覆盖范围较广

R37 命中 128 条，表明单期 CAC 跳升并非个别记录；R36 命中 28 条，说明其中一部分已经形成连续上行。需要优先关注同时出现两类信号的渠道，但不能把单期跳升直接等同于趋势。

证据：
- R37 命中 128 条。
- R36 命中 28 条。

## 发现：持续上行比单期波动更接近结构性成本压力

R36 的连续 3 个完整月条件比 R37 的单期变化提供了更强的趋势证据。当前结果支持对连续上行渠道进行优先复核，但没有提供足够证据说明上行来自竞价、素材、流量质量或其他具体原因。

证据：
- R36 规则条件为连续 3 个完整月上升。
- R37 规则条件为 CAC 环比跳升超过 5 个百分点。

## 优先复核清单

优先复核同时命中 R36 和 R37 的渠道；具体渠道名称和周期应以对应 Rule Result 的 dimension 与 period 为准。

## 数据缺口

- 缺少渠道类型和外部竞价等补充证据，影响成本压力来源定位。
