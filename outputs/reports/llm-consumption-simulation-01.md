# 经营分析报告（LLM 消费模拟）

- 分析范围：S1 品类经营、S2 渠道 CAC 信号、S3 投放风险
- 数据周期：2025-08—2025-10
- 数据来源：`outputs/engine/rule_results.json`，Schema 1.0
- 使用边界：只采用 Rule Engine 已输出的指标、证据与规则判定；不计算新指标，不转换数值格式，不推断原因。

## 一、管理摘要：品类下行信号与渠道 CAC 上行需要同步关注

### 总体判断

品类经营已命中 R9“系统性下跌”，渠道侧也存在命中 R36“CAC连续上升”和 R37“CAC环比跳升”的对象。当前应分别复核品类首单营收变化与具体渠道 CAC 变化，但事实包不足以解释原因或确定经营动作。

### 关键发现

- **品类下行具有全局性规则信号。** 2025-08—2025-10，满足 R5 连续下降条件的品类数为 10，命中 R9“系统性下跌”；规则阈值为“> 3个品类连续3个完整月下降”。[RR:S1/R9/__ALL__/2025-08~2025-10]
- **部分渠道出现持续 CAC 上行。** “喜鹊-XCX-垂直应用”在 2025-08—2025-10 的 CAC 率原始证据为 1.187941、1.480066、1.677792，命中 R36“CAC连续上升”；规则阈值为“连续3个完整月上升”。[RR:S2/R36/喜鹊-XCX-垂直应用/2025-08~2025-10]
- **S3 暂无可用于经营判断的命中规则。** 当前事实包中的 R61 均为 `hit=false`，因此本报告不据此形成投放健康或异常判断。

### 阅读边界

- `hit=false` 只表示对应规则未触发，不代表业务整体正常。
- 数值全部保留 Rule Engine 原始展示形式。
- 未获得规则事实支持的原因、影响和动作均标记为“数据不足/待确认”。

## 五、结论与待确认清单

### 已确认发现

- S1 已命中 R9“系统性下跌”、R5“核心品类下行趋势”和 R8“涨跌两极分化”。
- S2 已存在 R36“CAC连续上升”和 R37“CAC环比跳升”的渠道级命中事实。
- S3 没有 `hit=true` 结果，因此不形成经营判断。

### 待确认事项

- 为收入、CAC 和 ROI 指标补充口径编号、单位、展示值、指标版本与数据截至日。
- 为规则补充严重度、优先级、默认阈值状态和稳定规则结果 ID。
- 为 R8 极端增速补充基数、样本门槛及异常值标记。
- 如需客户结构分析，需要客户级购买、复购、留存、LTV 与客户分层事实。
- 如需判断投放整体状态，需要扩充 S3 规则覆盖，而不能用 R61 未命中代替完整结论。

## LLM 消费验证结果

### 可以生成的内容

- S1 的系统性下跌、具体品类连续下行和涨跌两极分化报告。
- S2 的渠道 CAC 连续上升、环比跳升提示及复核清单。
- S3 已评价规则的命中状态与原始证据展示。
- 基于已命中规则的管理摘要、经营含义边界和待确认清单。

### 因数据不足无法生成的内容

- 品类下行原因、利润影响、产品去留、资源配置和预测。
- 客户结构、客户分层、复购、留存、LTV 与沉默客户分析。
- 渠道命中对整体经营的影响权重，以及停投、扩量或预算调整判断。
- S3 的完整渠道结构或整体投放健康结论。

### 生成过程中发现的字段缺口

- 指标缺少 `metric_code`、`unit`、`display_value`、`caliber_ref`、`metric_version` 和 `as_of`。
- 规则缺少 `rule_version`、`severity`、`priority`、`is_default_caliber` 和默认口径提示。
- 证据缺少稳定 `evidence_id`、`rule_result_id` 和数据源血缘字段。
- 规则结果缺少 `not_evaluated/not_applicable` 状态及缺失原因，当前只能看到已生成的命中或未命中记录。
- 缺少用于多规则排序的影响范围、渠道规模或消耗权重字段。
